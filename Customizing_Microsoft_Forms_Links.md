# 🧩 Customizing Shared Microsoft Forms Links for Readable Text

When sharing Microsoft Forms links, you can make them more professional and readable by converting the long URL into a clean hyperlink or short link.

---

## 💻 In Outlook or Teams (Rich Text / HTML-capable)

1. Compose your message or email.
2. Type a readable phrase, such as:
   ```
   Complete the Safety Check Form
   ```
3. Highlight that text.
4. Press **Ctrl + K** (or select **Insert → Link**).
5. Paste the full Forms URL (e.g., `https://forms.office.com/r/XYZ123`) into the link field.
6. Click **OK**.

Your message will now display:
> [Complete the Safety Check Form](https://forms.office.com/r/XYZ123)

This method works in:
- **Outlook desktop and web**
- **Teams chat and channel posts**
- **Word documents**
- **SharePoint pages**

---

## 📱 In Plain Text Systems (SMS, Chat Apps, etc.)

If the system doesn’t support embedded links:
- Use a **URL shortener** that allows custom labels.

### Recommended options:
- **aka.ms** – Microsoft 365 internal link shortener (if enabled by your org)
- **bit.ly** – Public shortener with customizable endings
- **tinyurl.com** – Simple and free, ideal for quick sharing

Example shortened link:
```
bit.ly/SafetyCheckForm
```

---

## 🗓️ In Calendar Invites or Announcements

For event invites or intranet posts:
1. Open the **description** or **body** of the event.
2. Type a phrase like:
   ```
   Please submit your RSVP here.
   ```
3. Highlight it → click **Insert Link (🔗)** → paste your Forms URL.
4. Save.

Now attendees will see:
> Please [submit your RSVP here](https://forms.office.com/r/XYZ123)

---

## 🧱 For Company Branding

If you want all your company’s forms to have consistent, readable links:
- Use **aka.ms** with naming conventions:
  ```
  aka.ms/ITSurvey
  aka.ms/SafetyForm
  ```
- Or create redirects through your intranet:
  ```
  https://portal.company.com/forms/safetycheck
  ```
  which silently forwards to your Microsoft Forms URL.

---

## ✅ Summary

| Context | Best Method |
|----------|--------------|
| Outlook / Teams | Insert hyperlink with Ctrl + K |
| SharePoint / Calendar | Use built-in link button |
| SMS / Plain text | Use aka.ms or bit.ly short link |
| Company-wide | Create branded redirects |
