# 🛠 Accubid Change Order 14 – Print Layout Troubleshooting Guide

This guide walks you through resolving print layout display issues for **Change Order 14** in Accubid Classic or Enterprise.

---

## ✅ Step 1: Open Change Order 14

1. Launch **Accubid**
2. Open your project
3. Go to the **Change Orders** tab
4. Locate **Change Order 14** and double-click it

---

## ✅ Step 2: Launch Print Preview

1. Inside Change Order 14, go to the top menu
2. Click **File > Print Preview**
3. Alternatively, right-click the CO and select **Print**

---

## ✅ Step 3: Check the Report/Form Template

1. In Print Preview, locate the **Form/Report dropdown**
2. Compare the selected layout to a correct Change Order (e.g., CO 13 or CO 15)
3. If different, change the template to match:
   - Example: `Standard CO Layout`, `Custom Layout 2024`, etc.

---

## ✅ Step 4: Verify Assigned Form in Properties

1. Exit Print Preview
2. In the Change Orders list, right-click **Change Order 14**
3. Select **Properties**
4. Confirm the correct **form/template** is assigned
5. Change it to the standard one if needed
6. Save changes

---

## ✅ Step 5: Check Page Settings

1. Go back to **Print Preview**
2. Click **File > Page Setup**
3. Verify:
   - **Paper Size**: Typically Letter (8.5"x11")
   - **Orientation**: Portrait
   - **Margins**: Match prior COs
   - **Scale**: 100% or "Fit to Page"

---

## ✅ Step 6: Save and Reuse the Settings

1. With settings corrected, return to the Change Orders list
2. Right-click the corrected CO and choose **Save As Template**
3. Apply this layout template to future COs to ensure consistency

---

## 📤 Optional: Export to PDF

If the print preview still looks incorrect:
- Print to **Microsoft Print to PDF** or **Bluebeam**
- Check layout outside of Accubid
- If it looks correct externally, issue is likely preview-only

---

## 🧠 Tip:

A mismatch in layout is often caused by:
- Copying a Change Order from another project
- Inheriting old formatting from a legacy template
- Forgetting to reassign the correct form
