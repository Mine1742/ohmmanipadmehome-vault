# 🔵 Bluebeam Cloud vs Bluebeam Revu on iPad

## 🧭 Overview

This note outlines the key differences between **Bluebeam Cloud** and **Bluebeam Revu on iPad**, focusing on platform access, use cases, features, and collaboration capabilities.

---

## 🔵 Bluebeam Cloud

### ✅ What It Is
A **browser-based** suite of tools included with Bluebeam Core and Complete plans.

### 📱 Access
- No installation required
- Runs on iPad, desktop, or any web browser

### 🌐 Primary Use
- Field collaboration and document workflows
- Punch lists, RFIs, and submittals via Field Tools

### 🔧 Key Features
- Access to Studio Projects and uploaded PDFs
- Create and track RFIs, punch items, submittals
- Basic markup tools
- Real-time collaboration (limited markup compared to Revu)
- Drawings and document management via cloud storage
- Does **not** support offline use

---

## 🟦 Bluebeam Revu on iPad

### ✅ What It Is
A **native iOS app** designed specifically for iPad, offering more powerful markup capabilities.

### 📱 Access
- Download from the Apple App Store
- Requires Revu license (Core or Complete plan)

### 🧰 Primary Use
- PDF markup and review in the field or office
- Offline access to documents

### 🔧 Key Features
- Advanced markup tools (clouds, callouts, measurements, tool chests)
- Limited custom profiles/toolsets (compared to desktop)
- Work offline on local files
- Studio Sessions and Studio Projects integration

---

## 🔍 Feature Comparison

| Feature/Function             | Bluebeam Cloud         | Bluebeam Revu on iPad        |
|-----------------------------|------------------------|-------------------------------|
| Platform                    | Web browser            | iOS app (iPad only)          |
| Installation Required       | ❌                     | ✅ (App Store)               |
| Collaboration               | ✅ Real-time via Studio | ✅ Sessions/Projects         |
| Punch, RFI, Submittals      | ✅ Built-in workflows   | ❌ Manual workaround         |
| Markup Tools                | Basic                  | Full suite                   |
| Works Offline               | ❌                     | ✅                            |
| Ideal For                   | Field data + light use | Advanced markup & review     |
