# Customer Event RSVP Options (Microsoft 365)

## Option 1: Microsoft Forms + Outlook Invitation (Recommended)

1. Go to [forms.office.com](https://forms.office.com) and select **New Form**.  
2. Title the form (for example, “Customer Event RSVP”) and add a short description such as “Please RSVP by selecting Yes or No below.”  
3. Add your questions:  
   - “Will you be attending?” → choices: Yes / No  
   - “Your Name”  
   - “Company” or “Email” (if needed for tracking)  
4. Under **Settings**, choose **Anyone with the link can respond** so external customers can submit without signing in.  
5. Select **Share**, copy the form link, and paste it into your email or Outlook calendar invite.  
6. In Outlook, compose a message like:  
   “We’re hosting our Customer Appreciation Event and would love for you to join us. Please RSVP using the link below.”  
   Add the Microsoft Forms link as a hyperlink or button labeled “RSVP Here.”  

All responses will automatically appear in Microsoft Forms, and you can export them to Excel for tracking attendance.

---

## Option 2: Teams Meeting with Registration (For Virtual Events)

1. In Outlook or Teams, create a new Teams meeting.  
2. Enable the **Require registration** option.  
3. Customize the registration form with your company logo, event description, and any required fields (Name, Email, Company, etc.).  
4. Copy the registration link and include it in your event email instead of sending a direct meeting invite.

This option provides an automatic registration and confirmation process for each attendee.
