# 📄 Bulk PDF Conversion: Nitro PDF Pro vs Adobe Acrobat Pro DC

Both Nitro PDF and Adobe Acrobat Pro support bulk conversion of PDFs and other file types. Here's a breakdown of their features and step-by-step instructions.

---

## ✅ Nitro PDF Pro – Batch Conversion

### 🔄 Capabilities:
- Convert multiple files (Word, Excel, images) to PDF
- Convert PDFs to Word, Excel, etc.
- Combine PDFs
- Extract text or images

### 📂 How to Use:
1. Open **Nitro PDF Pro**
2. Go to **File > Batch Processing**
3. Choose an action:
   - Convert to PDF
   - Convert PDF to Word/Excel
   - Combine PDFs
   - Extract text
4. Click **Add Files** or **Add Folder**
5. Configure output settings (format, location, etc.)
6. Click **Run**

📝 *Optional:* Create and save batch sequences for repeat use.

---

## ✅ Adobe Acrobat Pro DC – Batch Conversion

### 🔄 Capabilities:
- Convert multiple PDFs to other formats (Word, Excel, PowerPoint)
- Create PDFs from multiple source files
- Run complex workflows with Action Wizard

### 📂 How to Use:
1. Open **Adobe Acrobat Pro DC**
2. Click **Tools > Action Wizard**
3. Choose a built-in action or create a new one
   - For conversion, use “Save & Export”
4. Add your files/folders
5. Choose the export format (e.g., Word, Excel)
6. Click **Start**

🛠 You can also include steps like watermarking, optimization, OCR, etc., in the Action Wizard.
