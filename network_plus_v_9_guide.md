# CompTIA Network+ (N10-009) V9 Study Guide

---

## 📚 Exam Objectives

### DOMAIN 1.0: Networking Fundamentals (24%)
- Network types: LAN, WAN, MAN, PAN, Internet, Intranet, Extranet
- Topologies: Star, Mesh, Ring, Bus, Hybrid
- Media: UTP, STP, Fiber (SMF, MMF), RJ45, LC, SC
- Wireless: Wi-Fi 4/5/6/6E/7, Bluetooth, Zigbee, frequencies
- Services: DHCP, DNS, NTP, FTP, HTTP(S), SMTP, SNMP
- Ports & Protocols: SSH (22), HTTP (80), HTTPS (443), DNS (53), FTP (20/21), RDP (3389), etc.

### DOMAIN 2.0: Network Implementations (19%)
- Routing: Static, Dynamic (RIP, OSPF, BGP, EIGRP)
- Devices: Router, Switch, AP, Firewall, IDS/IPS, VPN Concentrator
- Storage: NAS, SAN, iSCSI, SMB, NFS
- Advanced Configurations: VLANs, NAT, PAT, SDN, NFV, Virtual networking (VXLAN, VRF)

### DOMAIN 3.0: Network Operations (16%)
- Documentation: diagrams, baselines, change management
- High availability: redundancy, clustering, failover, load balancing
- Monitoring: SNMP, syslog, NetFlow, baselines, QoS
- Troubleshooting methodology: identify, theorize, test, resolve, document

### DOMAIN 4.0: Network Security (19%)
- Security concepts: CIA triad, least privilege, zero trust, defense in depth
- Threats: DDoS, phishing, malware, insider threats
- Hardening: ACLs, port security, disable unused ports, secure protocols
- Wireless security: WPA2/WPA3, PSK, Enterprise, RADIUS, 802.1X
- Remote access: VPN (SSL/TLS, IPSec), RADIUS, TACACS+, LDAP

### DOMAIN 5.0: Network Troubleshooting (22%)
- Tools: ping, tracert, nslookup, netstat, tcpdump, Wireshark
- Common issues: hardware failures, misconfigurations, DHCP/DNS issues, wireless interference
- Wireless troubleshooting: channel overlap, authentication failures, rogue APs
- Service troubleshooting: DNS, DHCP, firewall blocking

## 📅 2-Week Intensive Study Plan

### WEEK 1: Core Concepts + Security

**Day 1: Networking Basics**
- Network types, Topologies, OSI/TCP-IP, Ports & Protocols
- Lab: tracert & ping

**Day 2: IP Addressing & Routing**
- IPv4/IPv6, Subnetting, Routing protocols
- Lab: Subnetting exercises

**Day 3: Devices & Wireless**
- Router, Switch, Firewall, VLANs, Wi-Fi Standards, Wireless Security
- Lab: VLAN setup in Packet Tracer

**Day 4: Network Services**
- DHCP, DNS, NTP, VPNs, Remote Access
- Lab: DHCP/DNS virtual lab

**Day 5: Security Concepts**
- CIA Triad, Attacks, Hardening, Wireless Security
- Lab: Secure a wireless network

**Day 6: Network Operations**
- Documentation, Monitoring, High Availability
- Lab: Wireshark traffic capture

**Day 7: Troubleshooting**
- Troubleshooting methodology, Common issues, Tools
- Lab: Troubleshooting scenarios in Packet Tracer

---

### WEEK 2: Reinforcement + Practice

**Day 8: Storage & Virtual Networking**
- NAS, SAN, iSCSI, SMB, NFS, VLAN, SDN
- Lab: iSCSI/shared folders in VMs

**Day 9: Advanced Troubleshooting**
- Wireless, Remote access, Service troubleshooting
- Lab: Wireless troubleshooting

**Day 10: Review Domains 1 & 2**
- Practice quizzes + weak areas review

**Day 11: Review Domains 3 & 4**
- Practice quizzes + weak areas review

**Day 12: Review Domain 5 + Full Practice Test #1**

**Day 13: Focus Review + Flashcards**
