#groups 

[[Group type differences]]

Microsoft Teams & Microsoft 365 Groups
To set up a space for people to collaborate and work together on files, create a Microsoft 365 group. If you want, you can add Microsoft Teams. Teams lets people communicate through chat, calls, and online meetings.Learn about ‎Microsoft Teams‎

Distribution list groups
To save a list of email addresses for broad mailings, create a distribution list group.
It can take up to an hour for new distribution list groups to appear. To see them immediately.go to the Exchange admin center.

Security groups
To grant access to resources, create a security group or mail-enabled security group. A security group can include devices to be used in mobile device management. 

A mail-enabled security group can only include users, and can also have a group email address.
It can take up to an hour for new mail-enabled security groups to appear. To see them immediately, go to the Exchange admin center..
