# How to Log Into Smartsheet in Incognito Mode

1. **Open an Incognito / Private Window**
    
    - If using **Microsoft Edge** → click the three dots ⋯ in the top-right → select **New InPrivate Window**.
        
    - If using **Google Chrome** → click the three dots ⋯ in the top-right → select **New Incognito Window**.
        
2. **Go to Smartsheet**
    
    - In the address bar, type:
        
        `app.smartsheet.com`
        
    - If prompted, choose **Continue to Mobile Web**.
        
3. **Log in with the emergency support account**
    
    - Username: **emergencysupport@archkey.com**
        
    - Password: _(use the provided password)_
        
4. **Complete Authentication**
    
    - Approve the sign-in request on your phone when prompted.
