# 🧰 Microsoft Project Plan 3 Installation Guide (When Landing on M365 Copilot Page)

This guide helps troubleshoot and navigate the Microsoft 365 portal to install **Microsoft Project Plan 3**, especially if you’re redirected to the **Microsoft 365 Copilot** page.

---

## ✅ Observations When Redirected to Copilot Page

1. You're successfully **logged into Microsoft 365**.
2. Your organization might have **Copilot enabled or promoted**—this doesn't impact the install process directly.
3. The **Project install option may be buried** or not visible on the main page.

---

## 🔍 Step-by-Step Installation Methods

### 🛠️ Method 1: From "Install apps" on Main Portal Page

1. On the M365 Copilot or home portal page, look for an **“Install apps”** button in the top-right.
2. Click the download icon or label.
3. This should redirect to your licensed software list.
4. Look for **Microsoft Project** and click **Install**.

---

### ⚙️ Method 2: Via Account Settings (More Reliable)

1. Click your **profile icon** or initials in the top-right corner.
2. Select **"View account"** or **"My Microsoft 365 profile"**.
3. On the account page, locate:
    - **"Office apps"**
    - **"Installs"**
    - **"Software"**
    - **"Manage app installs"**
4. Click the relevant link.
5. Find **Microsoft Project** in the list.
6. Click **Install** to download the `Setup.exe`.

---

### 🔗 Method 3: Direct Install Link (Only if Provided by Admin)

If IT provides a direct link, you can use it—but it's safer to install through the portal to match your license.

---

## 🚀 After Clicking "Install"

1. A small file (typically `Setup.exe`) will download.
2. Run the installer to trigger **Click-to-Run installation**.
3. Project will install automatically and **activate using your M365 account**.
4. You can launch it via the **Start Menu** post-install.

---

## 🧯 Troubleshooting

If you can't find the "Install" option for Project:

- Ensure your **Project Plan 3 license is assigned and active**.
- Confirm with your **Microsoft 365 Admin** if:
  - Project is deployed differently in your org.
  - Custom deployment or endpoint manager is used.
  - Permissions restrict self-installs.
