# 🖊️ How to Mark Up Drawings in Bluebeam Revu 20.3.3 (Extreme License)

This guide explains how to use **Bluebeam Revu 20.3.3 with the Extreme license** to mark up construction or architectural drawings efficiently.

---

## 🧰 Step 1: Open a Drawing

1. Launch **Bluebeam Revu 20.3.3**
2. Go to `File > Open` and select the PDF drawing
3. Use the **Thumbnails panel** to navigate between sheets

---

## ✏️ Step 2: Use the Markup Toolbar

Access markup tools from:
- The **Markup Toolbar**
- `Tools > Markup` menu
- **Tool Chest**

### ✨ Common Tools:
- **Text Box** (`T`)
- **Callout** (arrowed comment)
- **Cloud**
- **Rectangle / Ellipse / Polygon**
- **Highlight / Pen / Pencil**
- **Stamp Tool** (use built-in or custom stamps)

---

## 🧩 Step 3: Customize Markup Appearance

1. Select any markup on the drawing
2. Use the **Properties Panel** to adjust:
   - Line style, color, fill
   - Font, size, text alignment
3. Right-click the markup and choose **Add to Tool Chest** for reuse

---

## 📐 Step 4: Measurement Tools (Optional)

1. Open the **Measurements** toolbar
2. Calibrate the drawing:
   - `Measurements > Calibrate`
   - Click two points and enter actual length
3. Use:
   - **Length**
   - **Area**
   - **Volume**
   - **Perimeter**
4. Measurement markups appear in the **Markup List** for tracking

---

## 🗂️ Step 5: Organize and Export Markups

- Use the **Markup List** (bottom panel) to:
  - Sort by author, date, page, type
  - Filter for specific layers or users
- Export summary:
  - `Summary > CSV, PDF, XML` for report generation
- Create **Custom Columns** for statuses or comments

---

## 🔒 Bonus (Extreme License Only)

- Use **Batch Tools** under `File > Batch`:
  - **Batch Sign & Seal**
  - **Batch Link**
  - **Batch Slip Sheet**
- Automate document processing workflows at scale

---

## 💡 Tips

- Use **Layers** to organize markup visibility
- Set default markup properties via **Tool Chest > Right Click > Properties**
- Assign statuses like "Reviewed", "Accepted", "For Revision" in the Markup List
