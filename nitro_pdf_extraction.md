# Extracting Data from a PDF Using Nitro Pro

## Basic Extraction Options

### Option 1: Copy Text Manually
1. Open the PDF in **Nitro Pro**.
2. Go to the **Home** tab and click **Select**.
3. Highlight the text.
4. Right-click and choose **Copy**.
5. Paste into a text editor.

### Option 2: Export as Word, Excel, or Text
1. Open the PDF in Nitro Pro.
2. Click on the **Convert** tab.
3. Choose **To Word**, **To Excel**, or **To Text**.
4. Select export location and confirm settings.
5. Click **Convert**.

> *Best for exporting tables or large chunks of content.*

### Option 3: Extract Pages
1. Click on the **Organize** tab.
2. Select **Extract**.
3. Choose pages and click **Extract**.
4. Save the new file.

## Addressing Password Prompts

If you receive a password prompt, the PDF is likely **secured** with restrictions. There are two types:

- **Open (User) Password:** Required to view the file.
- **Permissions (Owner) Password:** Restricts actions like copying or converting.

### If You Know the Password
1. Go to **File > Document Properties > Security**.
2. Change or remove restrictions.
3. Save the unprotected version.

### If You Don’t Know the Password
- **Check permissions**: Navigate to `File > Document Properties > Security` to confirm what is restricted.
- **Request an unprotected version** from the file's creator.
- **Try Printing to PDF**:
  1. Open the file and click **File > Print**.
  2. Select **Nitro PDF Creator** or similar virtual printer.
  3. Save the printout as a new file.
  4. Try extraction again.

> ⚠️ Only bypass protections if you have permission or ownership rights.

---

## Tips for Best Results
- Use **OCR** under the **Convert** tab if the file is a scanned image.
- Use **Excel export** for structured tables.
- Avoid copy-pasting from protected files to maintain formatting.
