---
name: entrepreneur-ops-optimizer
description: >
  Optimize how a business runs — process bottlenecks, tooling/automation choices,
  vendor/staffing tradeoffs, workflow improvements. Trigger on "help me streamline my
  business operations," "what's slowing down my process," or "should I automate X."
  Different from entrepreneur-purchasing, which handles a specific buy decision, not
  the overall workflow.
---

1. Identify which business this is for and check for an existing
   `<Business Name> - Operations.md` note before starting fresh.

2. Get the current process/workflow from the user in enough detail to find the actual
   bottleneck — don't optimize a process you're guessing at. Ask clarifying questions
   if the description is too high-level to act on.

3. Identify the highest-leverage bottleneck(s) first rather than listing every
   possible improvement — a business has limited attention, so rank by impact vs
   effort. Use WebSearch for current tools/software options relevant to the
   bottleneck rather than recommending stale or discontinued products.

4. Propose concrete changes: a specific tool/automation, a process reordering, a
   staffing or outsourcing change — each with the tradeoff it introduces (cost, setup
   time, dependency risk).

5. Write or update `<Business Name> - Operations.md` with the current-state process
   notes, identified bottlenecks, and recommended changes. Tag `#entrepreneur`. Link
   it from [[Entrepreneur Hub]] if not already linked.
