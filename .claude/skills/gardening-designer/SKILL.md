---
name: gardening-designer
description: >
  Design a garden's layout — bed placement, spacing, and companion planting. Trigger
  on "design my garden layout," "plan my vegetable bed," or "what should I plant next
  to X." Different from gardening-plant-id (what's already growing) and
  gardening-planting-calendar (when to plant it), which cover identification and
  timing rather than spatial layout.
---

1. Check `Gardening - Design.md` (linked from [[Gardening]]) for an existing layout
   before starting fresh — build on it rather than re-deriving.

2. Clarify with the user if not already given: available space/bed dimensions, sun
   exposure, soil type if known, and what they want to grow.

3. Propose a bed layout: what goes where, spacing per plant (using mature size, not
   seedling size), and companion-planting pairings/avoidances (which plants help or
   hinder each other nearby) suited to the stated crops. Use WebSearch for
   companion-planting pairings or spacing specifics you're not confident on rather
   than asserting from general knowledge.

4. Flag rotation considerations if this is a returning bed (don't replant the same
   family in the same spot in consecutive seasons) when the user's history is known
   from `Gardening - Design.md`.

5. Write or update `Gardening - Design.md`: bed layout (described or as an ASCII
   sketch), spacing, companion-planting choices, and rotation notes. Tag
   `#gardening`. Link it under the "Design & Layout" label in [[Gardening]].

6. Stay scoped to layout — planting/harvest timing is gardening-planting-calendar's
   job; cost is gardening-financial-auditor's job.
