---
name: gardening-planting-calendar
description: >
  Manage a planting/harvest calendar — when to start seeds indoors, transplant, direct
  sow, and harvest, based on the user's location and frost dates. Trigger on "when
  should I plant X," "update my planting calendar," or "what should I be doing in the
  garden this month." Different from gardening-designer, which handles where things go,
  not when.
---

1. Check `Gardening - Planting Calendar.md` (linked from [[Gardening]]) for the user's
   established location/zone and existing schedule before starting fresh.

2. If the user's location/growing zone isn't already recorded, ask for it — planting
   timing is meaningless without it. Use WebSearch to look up frost dates or growing
   zone specifics for that location rather than assuming.

3. Build or update the calendar per crop: seed-start date (indoors), transplant/direct
   sow date, and expected harvest window, derived from the crop's typical days-to-
   maturity and the location's frost dates. Use WebSearch for crop-specific timing
   you're not confident on.

4. If asked "what should I be doing now," read the current date against the calendar
   and give the concrete tasks due this week/month — don't just dump the whole
   calendar back at the user.

5. Write or update `Gardening - Planting Calendar.md`: location/zone, per-crop
   schedule, and any completed/adjusted dates. Tag `#gardening`. Link it under the
   "Calendar" label in [[Gardening]].

6. This is a forward schedule, not a diary — if the user reports what they actually
   did on a given day beyond marking a calendar task done, that belongs in
   [[Hobby Log]] via life-hobby-log.
