# 🧰 Microsoft PowerToys User Guide

Microsoft PowerToys is a set of utilities for power users to tune and streamline their Windows experience for greater productivity.

---

## 🚀 Installation

1. Download from the official GitHub release page:  
   [https://github.com/microsoft/PowerToys/releases](https://github.com/microsoft/PowerToys/releases)

2. Or install via Microsoft Store:  
   Search for **PowerToys**.

3. Once installed, PowerToys runs in the system tray. Right-click the icon to access settings.

---

## 🧩 Core Utilities

### 🔹 PowerRename
Batch rename files using find-and-replace or regex.

- Open File Explorer → Select files → Right-click → **PowerRename**
- Supports **regex**, case sensitivity, file extension targeting
- Preview changes before renaming

### 🔹 FancyZones
Create custom window layouts for multitasking.

- Access via PowerToys settings → FancyZones
- Use **Win + `** to trigger zone editor
- Hold **Shift** while dragging windows to snap into zones

### 🔹 PowerToys Run (App Launcher)
Quickly open files, apps, folders, or run commands.

- Shortcut: **Alt + Space**
- Type to search
- Supports plugins like calculator, shell commands, etc.

### 🔹 Keyboard Manager
Remap keys and shortcuts.

- Reassign single keys (e.g., Caps Lock → Esc)
- Remap key combinations (e.g., Ctrl+C → Ctrl+Shift+C)

### 🔹 Color Picker
Pick and copy any color on screen.

- Shortcut: **Win + Shift + C**
- Outputs HEX, RGB, HSL formats

### 🔹 Image Resizer
Batch resize images from File Explorer.

- Right-click image files → **Resize pictures**
- Choose preset sizes or custom dimensions

### 🔹 Text Extractor
OCR tool to extract text from screen images.

- Shortcut: **Win + Shift + T**
- Draw a box to extract visible text

### 🔹 Mouse Utilities
Includes:
- **Mouse Highlighter** (shows clicks)
- **Find My Mouse** (double Ctrl to spotlight mouse location)
- **Mouse Pointer Crosshairs**

### 🔹 File Locksmith
Find out what app is using a locked file.

- Right-click a locked file → **What's using this file?**
- Shows locking process so you can close it

### 🔹 Hosts File Editor
Easily edit your `hosts` file with a built-in UI.

---

## ⚙️ General Settings

- **Run at startup**
- **Check for updates**
- Configure per-utility settings via sidebar in PowerToys Settings

---

## 🧠 Tips

- Most tools have global hotkeys you can customize.
- Use **PowerToys Run** instead of Windows Search for faster results.
- Use **FancyZones** with multi-monitor setups for enhanced productivity.
