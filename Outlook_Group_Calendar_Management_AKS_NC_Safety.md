# Outlook Calendar Task – Create and Manage Group Calendar

## Request Summary

**Task:**  
Create a new shared calendar in Outlook and manage permissions for specific users. Then delete an outdated calendar.

---

## Step-by-Step Instructions

### 1. Create the New Shared Group Calendar

1. Open **Outlook Desktop App** (Microsoft 365).
2. Navigate to the **Calendar** tab.
3. Click **Add Calendar > Create New Blank Calendar**.
4. Name the calendar:  
   `AKS North Central Safety Vacation Calendar`
5. Choose the **Calendar Folder Location** (typically under "My Calendars").
6. Click **OK** to create the calendar.

---

### 2. Share Calendar with Specific Users

1. In the **Calendar view**, right-click `AKS North Central Safety Vacation Calendar`.
2. Select **Sharing Permissions** (or **Properties > Permissions** depending on version).
3. Click **Add** and search each of the following users:
   - Rick Crestik
   - Phil Deboer
   - Steven Sarlette
   - Collin Somers
4. Assign the permission level **"Can view all details and edit"** (use “Editor” role).
5. Click **OK** or **Apply** to save permissions.

---

### 3. Remove the Old Calendar

1. In the **Calendar view**, locate:  
   `New Safety Vacation Calendar # 2`
2. Right-click the calendar and select **Delete Calendar**.
3. Confirm deletion.

🛑 **Note:** This only removes the calendar from your view if it was shared. If you are the owner, it deletes the actual calendar.

---

- [x] `New Safety Vacation Calendar # 2` deleted from account.

## Tips

- Always confirm user names via Global Address List to ensure proper access.
- If using **Outlook Web Access (OWA)**, similar steps apply under **Calendar > Add Calendar > Create Blank**.
