# 🛠 Accubid Change Order 16 – Print Layout Troubleshooting Guide

If your **Change Order 16** in Accubid is not displaying correctly in **Print Preview**, the issue likely stems from a misconfigured layout template, form assignment, or print settings. Here's how to correct it.

---

## ✅ Step 1: Check the Assigned Print Form

1. Open **Change Order 16** in Accubid
2. Go to **Print Preview**
3. In the preview window, look for the **Form Name** or **Layout Template** field
4. Compare it to another Change Order (e.g., Change Order 15) that displays properly
5. Switch the layout to the known-good form (e.g., `Standard CO Layout`, `Change Order Template V2`, etc.)

> 🔄 Form mismatches are common when copying or editing from older projects.

---

## ✅ Step 2: Reassign the Change Order to the Correct Form

1. Exit Print Preview
2. Navigate to **Change Orders** from the main Accubid menu
3. Locate Change Order 16
4. Right-click and choose **Properties** or **Form Assignment**
5. Confirm that it's using the correct template or form name

✅ If not:
- Select the correct form from the dropdown
- Save the assignment
- Reopen Print Preview to confirm

---

## ✅ Step 3: Compare Layout Elements

1. Open a working change order (e.g., 15)
2. Enter **Print Preview** side by side with Change Order 16
3. Compare:
   - Title blocks
   - Signature fields
   - Page orientation
   - Header/footer content

> 💡 If Change Order 16 is missing fields, check whether it was created using a different **spec book** or **template version**.

---

## ✅ Step 4: Printer and Page Setup

1. From **Print Preview**, click **Page Setup**
2. Confirm the following:
   - **Paper Size**: usually Letter (8.5"x11") or ARCH D/E for large format
   - **Orientation**: Match with others (typically Portrait)
   - **Margins**: Standard or matching previous COs
   - **Scale**: Set to 100% or “Fit to Page”

---

## ✅ Step 5: Save the Layout as a Template (Optional)

If you corrected the layout manually:

1. In Print Preview, click **Save As Template**
2. Name it something like: `CO_Standard_Template`
3. Apply this to future Change Orders to avoid rework

---

## 🔁 Still Not Working?

- Check for missing **custom fields**
- Confirm **Accubid project settings** haven’t changed
- Try **exporting to PDF** and check if layout issues persist

---

## 🧠 Tip:
Accubid may cache layout data. A full **restart** of the app after reassigning templates can fix preview glitches.
