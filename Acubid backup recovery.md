By default, backups for Change Order are stored under the user profile at C:\Users\%USERNAME%\AppData\Roaming\Accubid\ChangeOrder Pro 16\Backups. If you do not use the default location, you can check where your backups are stored by clicking Settings > Options > Auto Save/Backup in the program. Once your backup location is found, click into the project you'd like to restore. Each change number backup file will end with the designation .backup. Simply rename the file and remove this designation to make the change number active, the file should now end in .cn16. You can now open the change number, as well as copy/paste it to the projects active folder.
