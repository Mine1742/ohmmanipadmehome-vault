# Outlook Contacts vs. Auto-Complete List

Outlook uses **two different systems** for storing and suggesting email addresses:  
1. **Contacts (People app)** – permanent, user-managed entries.  
2. **Auto-Complete list (nickname cache)** – temporary, usage-based memory.

Understanding the difference helps avoid confusion when addresses don’t auto-populate.

---

## 📇 Contacts (People App)
- Stored in your **Contacts / People** folder.  
- Manually created or synced from external sources (Exchange, Office 365, mobile sync, etc.).  
- Permanent until deleted.  
- Available across devices if using Exchange or Office 365.  
- Supports full details: phone, company, notes, etc.

### When to Use
- For important people you want to **always be available**.  
- When you want to store more than just an email address.  

---

## ✉️ Auto-Complete List (Nickname Cache)
- Built automatically from addresses you’ve sent mail to.  
- Stored locally in Outlook profile (desktop) or in mailbox cache (Exchange/OWA).  
- Temporary: can be cleared or lost.  
- Only shows addresses you’ve actually used.  
- Can contain mistyped or outdated addresses.

### When to Use
- For quick access to **recently emailed people**.  
- Temporary or one-off addresses where you don’t want a full contact card.  

---

## 🔑 Key Differences
| Feature | Contacts | Auto-Complete |
|---------|----------|---------------|
| Storage | Permanent | Temporary cache |
| Source | Manually added / synced | Built from sent messages |
| Portability | Syncs across devices (Exchange/365) | Profile-specific (desktop) or mailbox (OWA) |
| Data | Full contact details | Email + display name only |
| Reliability | Always available | Can reset/lose entries |

---

## 🛠️ Best Practices
- Add **important people** to Contacts to ensure permanent availability.  
- Use Auto-Complete for convenience, but don’t rely on it as your only source.  
- Periodically **clean out bad Auto-Complete entries** (delete or reset).  
- If Auto-Complete fails, check Contacts for accuracy.
