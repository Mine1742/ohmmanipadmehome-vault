# Standardizing Outlook Folder Views (Single-Line View)

This guide explains how to set all your Outlook mail folders to a consistent single-line view with the reading pane on the right.

## 🎯 Goal

To achieve a compact, single-line view for emails in all Outlook folders, with the reading pane positioned on the right side.

## ✅ Steps

### 1. Select a Folder with the Desired View

Navigate to an Outlook folder that already uses the desired view (e.g., `67395.200 - ELCO Building B Childcare`). This will serve as the template.

### 2. Go to the "View" Tab

Click the **"View"** tab in the Outlook ribbon.

### 3. Change the View Settings (If Necessary)

- In the **"Current View"** group, click **"Change View"**.
- Choose **"Single"** or **"Compact"**, whichever provides the single-line look with the reading pane on the right.
- *(Optional)* Disable grouped messages by unchecking **"Show in Groups"** in the **"Arrangement"** group.

### 4. Open "View Settings"

In the **"Current View"** group, click **"View Settings"** to open the "Advanced View Settings" dialog.

### 5. Save the Current View *(Optional but Recommended)*

- Click **"Save Current View as a New View..."**
- Name the view (e.g., `My Preferred Single Line View`)
- Click **"OK"**

### 6. Apply the Current View to Other Mail Folders

- In "Advanced View Settings", click **"Apply Current View to Other Mail Folders..."**
- In the dialog:
  - Select the folders you want to apply the view to
  - Use `Ctrl`-click or `Shift`-click to select multiple
  - **Check** the box for **"Apply view to subfolders"**
- Click **"OK"**

### 7. Set the Reading Pane Position

- In the **"Layout"** group on the **"View"** tab, click **"Reading Pane"**
- Select **"Right"**

### 8. Repeat for Other Top-Level Folders *(If Necessary)*

You may need to repeat the steps for each top-level folder (e.g., shared mailboxes or archives) to propagate the view through those folder trees.

---

By following these steps, you'll ensure a consistent single-line email view across your Outlook folders, improving organization and readability.
