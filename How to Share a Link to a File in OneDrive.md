
## Overview
This guide explains how end users can share a link to a file stored in OneDrive, either from the web interface or directly from their computer.  

---

## From the OneDrive Web Interface
1. **Sign in** to [OneDrive](https://onedrive.live.com/) with your work or personal Microsoft account.  
2. **Locate the file** you want to share.  
3. **Right-click** the file and select **Share**.  
4. In the **Send link** window:  
   - Select **Copy link** to generate a shareable link.  
   - Or, enter an **email address** or **name** to send it directly.  
5. **Set permissions** as needed:  
   - **Anyone with the link** – Anyone can view (or edit, if allowed).  
   - **People in your organization** – Restricts access to internal users.  
   - **Specific people** – Only named recipients can access.  
6. Toggle **Allow editing** on/off as appropriate.  
7. Click **Copy** (to use in chat/email) or **Send** (to deliver via email).  

---

## From OneDrive on Your Computer (Windows or Mac)
1. Open **File Explorer** (Windows) or **Finder** (Mac).  
2. Navigate to your **OneDrive folder**.  
3. **Right-click** the file you want to share.  
4. Select **Share** (look for the blue cloud icon).  
5. Adjust **permissions** and choose **Copy link** or **Email**.  

---

## Quick Tips
- **External sharing**: Ensure your admin allows “Anyone with the link” before sharing outside your organization.  
- **Security**: Use **Specific people** for sensitive files.  
- **Permissions**: Double-check whether the link is **view-only** or **editable** before sending.
