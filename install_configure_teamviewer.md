



# Installing and Configuring TeamViewer

This guide outlines how to install and configure TeamViewer on a Windows PC for remote access and support.

## 🎯 Goal

To successfully install TeamViewer, set it up for remote access, and configure basic security settings.

---

## ✅ Step-by-Step Instructions

### 1. Download TeamViewer

- Go to the official website: [https://www.teamviewer.com](https://www.teamviewer.com)
- Click **Download for Free** (or select **Windows** if not automatically selected)
- Save the installer to your computer

### 2. Install TeamViewer

- Run the downloaded installer (`TeamViewer_Setup.exe`)
- Select the following options:
  - **Default Installation** (for personal/non-commercial use)
  - Accept the License Agreement
- Click **Finish** to complete the installation

### 3. Launch TeamViewer

- Open TeamViewer from your Start Menu or Desktop
- The **main dashboard** will display your **ID** and **password**, which are needed for remote support

---

## 🔒 Optional: Configure for Unattended Access

### 4. Set Up Easy Access

- In the TeamViewer main window, click **"Grant Easy Access"**
- Sign in or create a **TeamViewer account**
- Assign the device to your account to enable unattended remote access

### 5. Set a Personal Password

- Go to **Extras > Options > Security**
- Under **Personal Password**, enter a strong password
- This ensures you can connect remotely without needing a new random password each time

---

## 🛡️ Recommended Security Settings

- **Disable Random Passwords**:
  - In **Options > Security**, set **Random password after each session** to **Disabled**
- **Enable Two-Factor Authentication**:
  - Visit your online TeamViewer account settings to enable 2FA
- **Restrict Access** (for advanced users):
  - Use the **Whitelist** feature under **Options > Security > Black and Whitelist**

---

## 🔄 Test Remote Access

- From another device, open TeamViewer
- Enter the **ID** of the computer you've set up
- Enter your personal password (or use Easy Access if enabled)
- Confirm that you can control the remote computer successfully

---

## 📌 Notes

- TeamViewer must be running on the host machine to accept remote connections
- You can configure TeamViewer to start with Windows under **Options > General**

By completing these steps, you’ll have TeamViewer installed and ready for secure remote access.
