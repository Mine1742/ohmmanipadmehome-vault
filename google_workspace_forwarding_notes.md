# Google Workspace Email Forwarding -- Notes

## User-Level Forwarding

1.  Log in to the Gmail account.
2.  Settings → See all settings.
3.  Forwarding and POP/IMAP.
4.  Add a forwarding address.
5.  Confirm the code sent to the destination mailbox.
6.  Select forwarding behavior.

## Admin-Level Forwarding

1.  Admin Console → Apps → Google Workspace → Gmail → Routing.
2.  Create a routing rule for inbound mail.
3.  Apply to specific user.
4.  Add more recipients (forward-to address).
5.  Save rule.

## Delegation

1.  Admin Console → Users → Select user.
2.  Email Delegation.
3.  Add a delegate.

## Summary

  Need                        Method
  --------------------------- ---------------
  Employee left               Admin Routing
  User wants own forwarding   User-Level
  Shared inbox                Delegation
  Conditional forwarding      Admin Rule
