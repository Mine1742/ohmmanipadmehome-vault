---
name: life-hobby-log
description: >
  Log progress on a personal hobby/project (HAM radio, bridge, sports cards, etc.).
  Trigger on requests like "log my HAM radio practice," "note my bridge session," or
  "update my sports card progress." Different from a hobby's static reference note,
  which documents facts/how-to rather than what you personally did.
---

1. Append a dated entry to [[Hobby Log]]: which hobby, what was done, and any
   outcome/decision. Don't invent details the user didn't give.

2. If the hobby has its own static reference note (e.g. [[HAM Radio Technician]],
   [[Bridge training]]), link it from the log entry — but keep the dated narrative in
   [[Hobby Log]], not scattered across each hobby's reference note.

3. Append-only — add new entries, don't rewrite past ones.
