---
name: gardening-plant-id
description: >
  Identify a plant (weed, volunteer seedling, disease/pest symptom on a plant) from a
  description or photo, and give basic care/action info. Trigger on "what plant is
  this," "identify what's growing in my garden bed," or "is this a weed or something I
  planted." Different from gardening-designer, which plans what to plant, not what's
  already there.
---

1. Check `Garden Plant ID Log.md` (linked from [[Gardening]]) for a prior entry on the
   same plant before re-identifying from scratch.

2. If a photo is provided, describe what you observe (leaf shape, growth habit, flower/
   fruit if present) and use that plus any location/season context to identify the
   plant. If only a text description is given, ask for the distinguishing details you
   need (leaf shape, size, where it's growing, time of year) rather than guessing from
   too little information.

3. State your confidence level plainly — plant ID from a description or single photo
   is often uncertain, and misidentifying a poisonous/invasive look-alike as safe is a
   real failure mode. Use WebSearch to cross-check identifying features against
   authoritative sources (extension office guides, reputable plant databases) rather
   than relying on a single guess, especially for anything the user might eat or
   handle bare-skinned.

4. Give the practical follow-up: is it wanted or a weed, is it toxic/invasive, and
   basic care or removal guidance.

5. Append an entry to `Garden Plant ID Log.md`: date, plant identified (or best
   guess + confidence), and the follow-up guidance given. Tag `#gardening`. Link the
   note under the "Plant ID" label in [[Gardening]] if not already linked.
