Here’s a simple but thorough guide to using **Markdown**, a lightweight markup language often used for formatting text in note-taking apps (like Obsidian), documentation, and websites like GitHub.

---

# **Markdown Guide**

Markdown allows you to format plain text easily. Below are examples of its syntax and output.

---

## **1. Headings**
Use `#` for headings. Add more `#` for smaller headings.

```markdown
# Heading 1
## Heading 2
### Heading 3
#### Heading 4
##### Heading 5
###### Heading 6
```

**Output:**

# Heading 1  
## Heading 2  
### Heading 3  
#### Heading 4  
##### Heading 5  
###### Heading 6  

---

## **2. Emphasis**
You can italicize or bold text.

```markdown
*Italic* or _Italic_
**Bold** or __Bold__
***Bold and Italic*** or ___Bold and Italic___
```

**Output:**

*Italic*  
**Bold**  
***Bold and Italic***  

---

## **3. Lists**

### **Unordered Lists**
Use `-`, `*`, or `+`.

```markdown
- Item 1
- Item 2
  - Subitem 2.1
  - Subitem 2.2
```

**Output:**

- Item 1
- Item 2
  - Subitem 2.1
  - Subitem 2.2

### **Ordered Lists**
Use numbers followed by periods.

```markdown
1. First
2. Second
3. Third
   1. Subitem 3.1
   2. Subitem 3.2
```

**Output:**

1. First  
2. Second  
3. Third  
   1. Subitem 3.1  
   2. Subitem 3.2  

---

## **4. Links**

```markdown
[Link Text](https://example.com)
```

**Output:**

[Link Text](https://example.com)

---

## **5. Images**

```markdown
![Alt Text](https://example.com/image.jpg)
```

**Output:**

![Alt Text](https://example.com/image.jpg)

---

## **6. Code Blocks**

### **Inline Code**
Use backticks (`).

```markdown
This is `inline code`.
```

**Output:**

This is `inline code`.

### **Code Blocks**
Use triple backticks (```).

```markdown
```
def hello_world():
    print("Hello, World!")
```
```

**Output:**

```
def hello_world():
    print("Hello, World!")
```

---

## **7. Blockquotes**

```markdown
> This is a blockquote.
> It can span multiple lines.
```

**Output:**

> This is a blockquote.  
> It can span multiple lines.

---

## **8. Tables**

Use pipes (`|`) and dashes (`-`).

```markdown
| Header 1 | Header 2 | Header 3 |
|----------|----------|----------|
| Row 1    | Data 1   | Data 2   |
| Row 2    | Data 3   | Data 4   |
```

**Output:**

| Header 1 | Header 2 | Header 3 |
|----------|----------|----------|
| Row 1    | Data 1   | Data 2   |
| Row 2    | Data 3   | Data 4   |

---

## **9. Horizontal Rules**

Use three or more `-`, `*`, or `_`.

```markdown
---
```

**Output:**

---

---

## **10. Checklists**

```markdown
- [ ] Task 1
- [x] Task 2 (completed)
```

**Output:**

- [ ] Task 1  
- [x] Task 2 (completed)  

---

## **11. Escaping Characters**

Use a backslash (`\`) to escape special characters.

```markdown
\*Not Italicized\*
```

**Output:**

\*Not Italicized\*

---

## **12. Adding HTML (Optional)**

Markdown supports inline HTML.

```markdown
<b>Bold Text</b>
```

**Output:**

<b>Bold Text</b>

---

### **Quick Reference Table**

| Syntax       | Description                |
|--------------|----------------------------|
| `#`          | Headings                  |
| `*italic*`   | Italic text               |
| `**bold**`   | Bold text                |
| `-` or `1.`  | Lists                    |
| `[text](url)`| Links                    |
| `![alt](url)`| Images                   |
| `` `code` `` | Inline code              |
| `>`          | Blockquotes              |
| `---`        | Horizontal Rule          |
