# 📂 How to Open a File from SharePoint in Bluebeam Revu

## ✅ Overview

This guide explains how to open PDF files stored in **SharePoint** using **Bluebeam Revu**, whether through direct integration, file syncing, or Bluebeam Cloud.

---

## 🖥️ Method 1: Use Bluebeam Revu’s SharePoint Integration

> ✔️ Works with **Bluebeam Revu 20** and **Revu 21 (with Bluebeam Cloud access)**

### 🔧 Steps:
1. In your browser:
   - Navigate to the SharePoint document library.
   - Click the **three dots (`...`)** next to the PDF or select **“Open in app”**.
   - Choose **Bluebeam Revu** (if available as an option).

2. In Bluebeam Revu:
   - Go to **File > Open**.
   - Enter the SharePoint library URL:
     ```
     https://[your-org].sharepoint.com/sites/[site-name]/[library-name]
     ```
   - Authenticate using your Microsoft 365 credentials if prompted.

---

## 🔄 Method 2: Sync SharePoint with OneDrive and Open Locally

> Ideal when direct SharePoint integration isn't available.

### 🔧 Steps:
1. In SharePoint:
   - Click the **“Sync”** button in the library toolbar.
   - This syncs the library to **OneDrive on your PC**.

2. On your computer:
   - Open **File Explorer**.
   - Navigate to the synced folder.
   - Right-click on the file and choose **Open with > Bluebeam Revu**.

---

## ☁️ Method 3: Use Bluebeam Cloud + SharePoint Integration

> Use this for browser-based markup with connected SharePoint libraries.

### 🔧 Steps:
1. In **Bluebeam Cloud**:
   - Navigate to **Drawings** or **Documents**.
   - Click **Upload > Connect Cloud Storage > SharePoint/OneDrive**.

2. Authenticate with your Microsoft 365 account.

3. Select a file to open and edit directly in **Bluebeam Cloud (web)**.

---

## 🧠 Pro Tips

- Enable **“Check out”** in SharePoint to avoid version conflicts.
- Set **Bluebeam Revu** as your default PDF handler in Windows.
- Use Bluebeam’s **session tools** for collaborative review after opening.
