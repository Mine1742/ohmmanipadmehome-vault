# Fix: Word Keeps Prompting "Save As PDF" and Disabling Editing

## 🧾 Problem
Microsoft Word keeps showing a "Save As" dialog that forces saving as a PDF, and the document becomes uneditable.

## 🔍 Common Causes
- Word is unlicensed or expired
- File is opened in viewer or PDF reflow mode
- Default printer is "Microsoft Print to PDF"
- Protected View is enabled
- File is actually a PDF
- File associations are broken

## 🛠️ Solutions

### 1. Check Word Activation
- File > Account > Product Information
- Ensure "Product Activated" is displayed

### 2. Confirm File Type
- Right-click > Properties
- Ensure file is `.docx`, not `.pdf`

### 3. Turn Off Protected View
- File > Options > Trust Center > Trust Center Settings > Protected View
- Uncheck all boxes

### 4. Check Default Printer
- Control Panel > Devices and Printers
- Set a physical printer or "XPS Document Writer" as default

### 5. Repair Office
- Settings > Apps > Microsoft 365 > Modify > Quick Repair
