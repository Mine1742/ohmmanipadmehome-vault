# Setting Up a Web UI for Your Local LLM

## Purpose
A Web UI allows you to interact with your local LLM from a browser interface.

## Options

| Tool | Link | Notes |
|---|---|---|
| Open WebUI | [https://github.com/open-webui/open-webui](https://github.com/open-webui/open-webui) | Popular Ollama-compatible Web UI |
| LM Studio | [https://lmstudio.ai/](https://lmstudio.ai/) | Easy GUI for GGUF models |
| Text Generation WebUI | [https://github.com/oobabooga/text-generation-webui](https://github.com/oobabooga/text-generation-webui) | Feature-rich for multiple backends |

## Installation Example (Open WebUI with Ollama)

```bash
git clone https://github.com/open-webui/open-webui.git
cd open-webui
docker compose up -d
```
