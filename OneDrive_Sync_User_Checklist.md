# OneDrive & SharePoint Sync Issue - User Checklist ✅

Use this checklist to walk through resolving issues where files aren't syncing between your SharePoint and OneDrive folders.

---

## 🔄 Basic Sync Checks

- [ ] I clicked **“Sync”** on the SharePoint document library page.
- [ ] I saw a confirmation from OneDrive that sync has started.
- [ ] I restarted my computer after syncing.

---

## ☁️ OneDrive Status

- [ ] I checked the **OneDrive cloud icon** in the system tray.
- [ ] There are no red ❌ or persistent blue 🔄 icons.
- [ ] I opened **“View sync problems”** (if available).

---

## 📁 File & Folder Issues

- [ ] No file or folder name exceeds 400 characters in path length.
- [ ] None of the filenames include characters like `: * ? " < > |`.
- [ ] I resolved any duplicate files named like `filename (computername).ext`.

---

## 👤 Account Verification

- [ ] I’m signed into OneDrive with my **Work or School account**.
- [ ] I confirmed my account under **Help & Settings > Settings > Account**.

---

## 🧮 Storage Quotas

- [ ] I verified my **SharePoint site** has storage space remaining.
- [ ] I checked my **OneDrive storage** at [onedrive.live.com](https://onedrive.live.com).

---

## 🛠 Restart or Re-sync

- [ ] I restarted OneDrive manually from the system tray.
- [ ] I unlinked and re-synced the folder if nothing else worked.

> **Tip:** To unlink and re-sync:
> 1. Stop sync from OneDrive settings (Account tab).
> 2. Return to SharePoint and click **“Sync”** again.

---

If this checklist does not resolve the issue, contact IT support with a screenshot of your OneDrive status and the steps you've completed.
